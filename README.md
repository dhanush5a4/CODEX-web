# Tech Writer Blog Website

A simple, single-page blog website you can run locally to publish your own technical posts.

## Features

- Create technical blog posts with title, author, tags, and content.
- Automatically saves posts to browser local storage.
- Lists published posts in reverse chronological order.
- One-click option to clear all posts.

## Run locally

Because this is a static website, you can open `index.html` directly in a browser.

Or run a tiny local server:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000>.
